# EgyDead TV
Android TV WebView wrapper for https://tv10.egydead.live/h3/.

## Build on GitHub (phone friendly)
1. Create a new public or private GitHub repository.
2. Upload all project files and folders, preserving `.github/workflows/build-apk.yml`.
3. Open **Actions** > **Build Android TV APK** > **Run workflow** (or push to main).
4. When finished, open the run and download the **EgyDeadTV-APK** artifact ZIP.
5. Extract `app-debug.apk`, copy it to the TV and install it (allow installation from this source if prompted).

Note: A website may block embedded WebView, video playback or remote navigation. This project is not yet device-tested.
